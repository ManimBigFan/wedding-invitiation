# Rustic Romance 모바일 청첩장

- [02 우리의 한 장면](https://manimbigfan.github.io/wedding-invitiation/rustic/?design=photo)
- [03 여백으로 전하는 마음](https://manimbigfan.github.io/wedding-invitiation/rustic/?design=emboss)

이기훈 · 한승미 / 2027년 3월 28일 오전 11시 30분 / 더채플앳청담. 실제 사진은 `../assets/our-moment.jpg`를 사용합니다.

## 파일

- `index.html`: 봉투와 표지, 편지·사진 전개, 초대글, 예식 정보, 갤러리, 달력, 길 안내, 사진·영상 참여 영역과 dialog.
- `styles.css`: 공통 레이아웃, 다른 두 시안, 접힌 편지와 글 등장 효과.
- `cover.css`: 버건디색 Wedding Post 표지, 사진 우표와 자동 봉투 도입.
- `postal-scene.css`: 봉투의 앞·뒷면, 안감, 덮개, 앞주머니와 인화 사진의 배치 및 인쇄용 화면.
- `stationery.css`: 하객용 바로가기, 초대글, 사진, 예식 일시·장소, 하객 스냅과 맺음말.
- `script.js`: 시안 선택, 갤러리 확대·색감 전환, 카운트다운, 일정 저장, 복사와 공유.
- `interactions.js`: 자동 봉투 연출 종료, 스크롤에 따른 편지·사진 전개, 줄 단위 글 등장과 움직임 줄이기 처리.
- `config.js`: 사진 전송 서비스 주소와 공개 업로드 한도. 비밀 키를 넣지 마세요.
- `guest-upload.js`: 파일 선택·미리보기·진행률·실제 전송·실패 재시도.

1안은 우표가 있는 실제 표지 종이가 봉투에서 올라와 제자리에 놓이는 자동 연출로 시작합니다. 열기·다시 보기·건너뛰기 버튼은 없습니다. 도입 연출 중 스크롤·키보드·터치·포커스 입력이 들어오면 즉시 완료하며, 움직임 줄이기 설정·직접 섹션 링크·뒤로/앞으로 탐색에서는 도입을 생략합니다.

표지는 실제 사진으로 만든 큰 우표와 들꽃 동판화를 사용합니다. `../assets/stamp-edge.svg`는 우표 가장자리, `../assets/postal-botanical.svg`는 한 색으로 찍는 꽃 그림입니다. 상단 메뉴에서 예식 일시·장소와 하객 스냅으로 바로 이동합니다. 세 시안의 비교 링크는 맨 아래의 “청첩장 시안 보기”에서 엽니다.

표지 다음의 편지 장면은 지원 환경에서 약 235svh 구간 동안 화면에 머뭅니다. 주소 면에 소인이 찍히고 봉투가 뒤집혀 안감이 보이는 덮개가 열립니다. 사진은 앞주머니에서 빠져나와 흑백에서 원래의 따뜻한 색으로 변하고, 그 아래에 두 줄이 나타납니다. 일반 세로 스크롤을 사용하며, 반대로 스크롤하면 이 전개도 되돌아갑니다. 초대글 아래의 한글 손글씨 서명은 처음 화면에 들어올 때 한 번 쓰입니다.

우표는 두 사람의 사진에 예식 날짜를 담아 결혼 소식을 전하는 표식입니다. 표지의 사진 우표와 봉투에 붙은 작은 우표에 같은 사진을 사용합니다. 예식 날짜의 원형 소인과 물결선은 우표와 편지에 걸쳐 놓입니다. 표지의 “소중한 당신께”와 봉투의 받는 분 표시가 이어지며 우표·소인은 클릭을 요구하지 않습니다.

본문의 제목·일부 문단은 170ms 간격으로 줄마다 약 0.95초에 걸쳐 한 번 나타납니다. 갤러리 사진도 기울어진 작은 인화 사진에서 제자리로 펼쳐집니다. 편지 장면과 갤러리는 기존 `our-moment.jpg`를 함께 사용합니다. 표지 우표는 클릭하지 않는 장식이고, 본문 갤러리 확대·색감 전환과 예식 정보·사진 전송 기능을 유지합니다. 반지 장면과 전용 렌더러는 제거했습니다.

G&S 같은 이니셜·모노그램 장식은 사용하지 않습니다. 봉투는 종이 질감과 접힘선으로 표현하고, 이름이 필요하면 제공된 전체 이름을 유지하세요.

## 최신 인터랙션 참고

최신 참고는 fromlilt의 [Cupid Express 공식 샘플](https://fromlilt.kr/preview/template/LILT_003)입니다. 우편물의 종이 조각이 스크롤에 따라 떨어져 회전하고, 밝은 종이 위의 사진으로 이어진 뒤 본문 문구가 차례로 나타나는 전개를 참고했습니다. Arta Atelier Rustic Romance의 아이보리 종이·사진 우표·차분한 서체에 이 움직임의 흐름을 적용합니다.

Cupid Express의 이미지·문구·코드는 복제하지 않습니다. 기존 커플 사진과 확인된 예식 정보를 사용하고, 프로젝트의 HTML/CSS/JavaScript로 구현합니다. 별도 3D 라이브러리나 반지 엔진은 필요하지 않습니다.

편지 장면의 상태는 `interactions.js`, 모양과 전환은 `postal-scene.css`에서 관리합니다. 뷰포트 높이 640px 미만·움직임 줄이기·필요한 CSS 기능 미지원에서는 사진과 두 줄을 일반 문서 흐름에 표시합니다. JavaScript가 없어도 사진과 본문을 볼 수 있습니다.

## 사진·영상 보내기

청첩장에서 이름과 파일을 고른 뒤 **올리기**를 누릅니다. 최대 100개, 파일당 80 MiB, 한 번에 총 1 GiB입니다. 각 파일은 서버 저장이 확인된 뒤 완료로 표시됩니다. 실패한 파일은 같은 화면에서 다시 전송할 수 있습니다.

프런트엔드는 GitHub Pages의 정적 파일입니다. 실제 업로드는 별도의 Sites 서버가 D1에 접수 정보를, 비공개 R2에 원본을 저장합니다. 다른 LLM에 전달하는 압축파일의 `upload-service/`에 서버 소스가 포함됩니다.

관리 화면: https://gihun-seungmi-wedding-snap.leegihun42.chatgpt.site/admin

청첩장을 만든 소유자 계정으로 ChatGPT 로그인해야 원본 조회·다운로드·삭제가 가능합니다. 하객에게는 사진 목록이나 원본 주소를 공개하지 않습니다. 서버 환경 변수 `ADMIN_EMAIL`은 관리 계정 확인용이며 서버의 비밀 환경 변수로 설정합니다. GitHub 소스에 넣지 않습니다.

실제 전송은 허용된 GitHub Pages 주소와 서비스 주소에서 사용합니다. ZIP에서 HTML을 직접 열면 디자인은 확인할 수 있지만 브라우저의 출처 정책상 실제 업로드는 라이브 주소에서 확인해야 합니다. 개발 시에는 서버의 허용 출처 목록을 명시적으로 수정하세요.

## 수정 및 배포

정적 파일은 별도 빌드 없이 저장소 `main`에 올리면 GitHub Pages가 배포합니다. 이름·문구·장소는 HTML, 예식 날짜는 `script.js`와 HTML 달력을 함께 변경합니다. 서버 배포는 `upload-service/README.md`를 참고하세요.

확인되지 않은 전화번호·계좌·주차 안내·경품 약속은 넣지 않았습니다. RSVP 수집 기능도 없습니다.
