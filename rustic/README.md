## 파일

- `index.html`: 초대글, 예식 정보, 갤러리, 달력, 길 안내, 사진·영상 참여 영역과 dialog.
- `styles.css`: 세 디자인의 레이아웃, 종이 질감, 모바일 스타일.
- `script.js`: 시안 선택, 갤러리 확대·색감 전환, 카운트다운, 일정 저장, 복사와 공유.
- `interactions.js`: 클릭 없는 자동 봉투 연출, 입력에 따른 즉시 완료, 스크롤 등장 효과. 움직임 줄이기 설정과 직접 섹션 링크에서는 봉투 연출을 생략합니다.
- `config.js`: 사진 전송 서비스 주소와 공개 업로드 한도. 비밀 키를 넣지 마세요.
- `guest-upload.js`: 파일 선택·미리보기·진행률·실제 전송·실패 재시도.

1안은 봉투 콘셉트를 유지하며, 들어오면 짧은 연출 뒤 봉투가 자동으로 열립니다. 누르는 동작을 요구하지 않고 열기·다시 보기·건너뛰기 버튼도 두지 않습니다. 스크롤·키보드·터치 입력이 들어오면 즉시 표지를 보여 줍니다. 움직임 줄이기 설정 또는 직접 섹션 링크에서는 봉투 연출을 생략합니다. 표지 우표는 정적인 장식이며, 본문 갤러리의 사진 확대 기능은 유지합니다.

G&S 같은 이니셜·모노그램 장식은 사용하지 않습니다. 봉투는 종이 질감과 접힘선으로 표현하고, 이름이 필요하면 제공된 전체 이름을 유지하세요.

## 사진·영상 보내기

청첩장에서 이름과 파일을 고른 뒤 **올리기**를 누릅니다. 최대 100개, 파일당 80 MiB, 한 번에 총 1 GiB입니다. 각 파일은 서버 저장이 확인된 뒤 완료로 표시됩니다. 실패한 파일은 같은 화면에서 다시 전송할 수 있습니다.

프런트엔드는 GitHub Pages의 정적 파일입니다. 실제 업로드는 별도의 Sites 서버가 D1에 접수 정보를, 비공개 R2에 원본을 저장합니다. 다른 LLM에 전달하는 압축파일의 `upload-service/`에 서버 소스가 포함됩니다.

관리 화면: https://gihun-seungmi-wedding-snap.leegihun42.chatgpt.site/admin

청첩장을 만든 소유자 계정으로 ChatGPT 로그인해야 원본 조회·다운로드·삭제가 가능합니다. 하객에게는 사진 목록이나 원본 주소를 공개하지 않습니다. 서버 환경 변수 `ADMIN_EMAIL`은 관리 계정 확인용이며 서버의 비밀 환경 변수로 설정합니다. GitHub 소스에 넣지 않습니다.

실제 전송은 허용된 GitHub Pages 주소와 서비스 주소에서 사용합니다. ZIP에서 HTML을 직접 열면 디자인은 확인할 수 있지만 브라우저의 출처 정책상 실제 업로드는 라이브 주소에서 확인해야 합니다. 개발 시에는 서버의 허용 출처 목록을 명시적으로 수정하세요.

## 수정 및 배포

정적 파일은 별도 빌드 없이 저장소 `main`에 올리면 GitHub Pages가 배포합니다. 이름·문구·장소는 HTML, 예식 날짜는 `script.js`와 HTML 달력을 함께 변경합니다. 서버 배포는 `upload-service/README.md`를 참고하세요.

확인되지 않은 전화번호·계좌·주차 안내·경품 약속은 넣지 않았습니다. RSVP 수집 기능도 없습니다.
